============================================================
1. TUJUAN APLIKASI
============================================================

Aplikasi ini digunakan sebagai sistem administrasi dan dashboard yayasan
pendidikan yang memiliki banyak sekolah, pengguna, pegawai, guru, kepala
sekolah, dan pengurus yayasan.

Aplikasi harus mendukung:
- Banyak sekolah di bawah satu yayasan.
- Banyak pengguna.
- Pengguna dapat memiliki peran berbeda.
- Hak akses berdasarkan role dan permission.
- Pembatasan data berdasarkan sekolah/yayasan.
- Super Admin dapat melihat seluruh data.
- Admin Yayasan dapat mengelola data yayasan.
- Admin Sekolah hanya dapat melihat/mengelola sekolahnya.
- Kepala Sekolah hanya dapat mengakses data sesuai kewenangannya.
- Guru hanya dapat mengakses data yang diberikan kepadanya.
- Riwayat aktivitas penting dapat dilacak.

============================================================
2. PRINSIP ARSITEKTUR
============================================================

Aplikasi menggunakan konsep MODULAR MONOLITH.

Artinya:
- Tetap satu project Laravel.
- Fitur dipisahkan secara rapi berdasarkan domain/modul.
- Tidak menggunakan microservice pada tahap awal.
- Lebih mudah dikembangkan, diuji, dan dipelihara.

Pemisahan penting:

ROLE
----
Menentukan posisi pengguna.
Contoh:
- super-admin
- admin-yayasan
- pengurus-yayasan
- admin-sekolah
- kepala-sekolah
- guru
- staf

PERMISSION
----------
Menentukan tindakan yang boleh dilakukan.
Contoh:
- school.view
- school.create
- school.update
- school.delete
- user.view
- user.create
- employee.view
- employee.update

DATA SCOPE
----------
Menentukan data mana yang boleh dilihat pengguna.

Contoh:
Admin Sekolah A boleh memiliki permission "employee.view",
tetapi hanya boleh melihat pegawai di Sekolah A.

Jadi:
ROLE != PERMISSION != DATA SCOPE

4. ROLE AWAL YANG DIRENCANAKAN
============================================================
